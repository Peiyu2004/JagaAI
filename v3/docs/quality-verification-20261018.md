## 在线语义检索

Ollama 使用项目配置的 `127.0.0.1:11435`；模型为 `qwen3-vl:2b-instruct` 与 `qwen3-embedding:0.6b`。实际模型调用成功，向量维度为 1024，摘要与原有索引一致，没有重建演示索引。

以下三种输入均返回相同排序的 9 个抽样片段，来自 `demo-kerb-waiting` 和 `demo-parking-people` 两段录像：

- `穿红衣服的人靠近白色汽车`
- `person wearing red near a white car`
- `orang berbaju merah dekat kereta putih`

前两条分别位于 01:39.2（0.7010）与 00:47（0.6612）。阈值仍为 0.65；另外 7 条使用已有的颜色/物体条件全部满足且分数至少 0.60 的规则，页面明确标注。匹配是待人工核查的线索，不证明身份或行为关系。

运行 `scripts/verify-person-search.py --rounds 3`，90/90 查询通过：39 次正例、15 次负例、24 次无人时段、9 次行为事件、3 次不支持行为。78 次语义查询中位数为 0.559 秒；首轮一次变体查询为 18.421 秒，其余最大 0.821 秒。首次视觉调用含加载约 133 秒，向量模型首次预热约 73 秒，不能据中位数保证每次低延迟。

在当前网页上，中、英、马来文分别于桌面/手机测试，共 6 组，均通过关键帧加载、命中时间定位与原录像实际播放。上述结果仅适用于本机演示集，不代表通用准确率。

## 复现

从 `v3` 目录，在按 README 安装依赖后运行：

```powershell
Push-Location frontend
npm run build
Pop-Location
Push-Location backend
../.venv/Scripts/python.exe -m pytest -q
Pop-Location
```

启动演示服务并安装本地模型后，在原始 8 段演示数据上运行：

```powershell
New-Item -ItemType Directory -Force output/playwright | Out-Null
./.venv/Scripts/python.exe scripts/verify-person-search.py --rounds 3 --report output/playwright/online-search.json
```

有写入的浏览器回归使用独立数据副本。原演示业务表和索引哈希前后相同；登录、搜索和观看录像正常产生运行审计记录。原始本机测试日志、截图、临时数据库与模型运行状态不作为项目源码提交。

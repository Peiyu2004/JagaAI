# P3 网页优化与回归验证

日期：2026-10-18。基线为 `ac0f771` 对应的本机生产构建；以下数据使用最终实现。

## 修改

- 工作台 8 个页面和居民入口通过 `React.lazy` 按需加载；已加载的模块复用。页面下载期间显示状态，下载失败后提供重新加载入口。告警深链接和加载期间发起的全局搜索均通过验证。
- 保留录像弹窗的即时打开方式，沿用原有焦点、Escape 和确认交互。
- 清理旧登录布局、相机网格、证据框等已无源码引用的 171 个 CSS 选择器。保留动态徽章、直播、区域和看板类族，以及仍有用途的响应式、动画和无障碍样式。没有按单页浏览器覆盖率批量删除样式。
- 提供真实的 `robots.txt`，返回 200 / text/plain。员工和居民报送入口统一使用 HTML `noindex,nofollow`。robots 允许读取页面上的 noindex，并阻止抓取 `/api/`；原有认证与授权逻辑保持不变。

页面拆分采用 [React lazy](https://react.dev/reference/react/lazy)。索引策略遵循 [Google 的 noindex 指南](https://developers.google.com/search/docs/crawling-indexing/block-indexing)：爬虫需要能够读取 noindex，不能用 robots 阻止抓取页面后再期待该指令生效。
